Ejercicio TDD Ecuacion de segundo grado
=========================================



## Kata Ecuación de segundo grado
codigo: ["Ejercicio de ecuacion segundo grado"](src/raiz_ecuacion_segundo_grado.py)


Crear un entorno virtual:

```bash
`python3 -m venv venv`
```
Activar el entorno virtual (Comando en Sistema Linux):

```bash
`source venv/bin/activate`
```

Instalar pytest:
```bash
(venv) $ `pip3 install -U pytest`
(venv) $ `pytest --version`
```

Crear documento requirements.txt:

```bash
`pip freeze > requirements.txt`
```

Instalar coverage:

```bash
`pip3 install pytest-cov`
```

Instalar black:

```bash
(venv) $ `pip3 install black`
```

comprobar el codigo con black:
```bash
`black --diff src/`
```
